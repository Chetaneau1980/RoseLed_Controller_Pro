# Contribuer / Contributing

---

## 🇫🇷 Français

Merci de votre intérêt pour le projet **RoseLed Controller Pro**.

### Comment contribuer ?

Vous pouvez contribuer de plusieurs façons :

- 🐞 Signaler un bug
- 💡 Proposer une amélioration
- 📚 Améliorer la documentation
- 🧪 Tester les nouvelles fonctionnalités
- 🔧 Soumettre une Pull Request

### Style de développement

Merci de respecter les règles suivantes :

- Code clair
- Architecture modulaire
- Documentation complète
- Commentaires en français
- Historique Git propre

### Objectif

Le **RoseLed Controller Pro** est un projet open source développé pour soutenir **Octobre Rose** grâce à un contrôleur professionnel ESP32 destiné aux LEDs WS2812B.

Merci pour votre contribution.
