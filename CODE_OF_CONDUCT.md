# 🌹 RoseLed Controller Pro

# Code de conduite / Code of Conduct

---

## 🇫🇷 Français

Le **RoseLed Controller Pro** est un projet open source.

Nous souhaitons maintenir une communauté accueillante, respectueuse et constructive.

### Nos valeurs

- 🤝 Respect de chacun
- 💬 Communication bienveillante
- 🛠️ Partage des connaissances
- 🌹 Soutien à la communauté Octobre Rose

Les comportements insultants, discriminatoires ou agressifs ne seront pas tolérés.

Merci de contribuer dans un esprit de respect et de collaboration.

---

## 🇬🇧 English

The **RoseLed Controller Pro** is an open source project.

We are committed to maintaining a welcoming, respectful and constructive community.

### Our values

- 🤝 Respect for everyone
- 💬 Positive communication
- 🛠️ Knowledge sharing
- 🌹 Support for the Pink October community

Insulting, discriminatory or aggressive behavior will not be tolerated.

Thank you for contributing in a respectful and collaborative spirit.
