# 🌹 RoseLed Controller Pro

> Contrôleur ESP32 pour LEDs WS2812B, développé pour le projet Octobre Rose.

---

## 🇫🇷 Français

**RoseLed Controller Pro** est un projet Open Source basé sur un ESP32 permettant de piloter un ensemble de LEDs WS2812B depuis une application Android via Bluetooth Classic.

Le projet a été conçu avec une architecture modulaire afin de rester simple à comprendre, à maintenir et à faire évoluer.

### ✨ Fonctionnalités

- 🌹 Animation spéciale Octobre Rose
- 🎨 Gestion de la couleur fixe
- ✨ Plusieurs animations et effets lumineux
- 🔥 Effet Feu
- 🌊 Effet Océan
- ⚡ Effet Flash
- 💡 Gestion de la luminosité
- 🛡️ Limitation de luminosité pour la sécurité
- 📱 Application Android dédiée
- 📶 Communication Bluetooth Classic avec l'ESP32
- ⏻ Commande ON/OFF
- 💾 Mémorisation de paramètres
- 💡 Bibliothèque FastLED
- 🛠️ Architecture firmware modulaire

### 🔧 Firmware ESP32

Environnement de développement :

- ESP32-WROOM-32E
- Arduino IDE
- Bluetooth Classic
- FastLED
- LEDs WS2812B

État actuel :

- ✅ Firmware compilé et validé
- ✅ Zéro erreur de compilation
- ✅ Bluetooth opérationnel
- ✅ Animations intégrées
- ✅ Gestion de la luminosité
- ✅ Limitation de sécurité intégrée
- ✅ Communication avec l'application Android

### 📱 Application Android

L'application Android permet de piloter le RoseLed Controller Pro directement depuis un smartphone compatible Bluetooth Classic.

Fonctions principales :

- Connexion Bluetooth au contrôleur
- Sélection des animations
- Réglage de la couleur
- Réglage de la luminosité
- Réglage de la vitesse
- Gestion des favoris
- Paramètres
- Minuteur
- Écran À propos

- 📶 Bluetooth Classic communication
- ⏻ ON/OFF control
